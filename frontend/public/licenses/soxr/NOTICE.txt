InterviewMate's voice analysis resamples audio in the browser with the SoX Resampler library (libsoxr),
compiled to WebAssembly.

The file is unmodified and is loaded as a separate WebAssembly module, so it can be replaced with another
build of libsoxr. To rebuild it, follow the build instructions of wasm-audio-resampler, which compile
libsoxr with Emscripten.
